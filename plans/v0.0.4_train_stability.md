# v0.0.4：训练稳定性、真实吞吐与短程对照

日期：2026-09-29。前置 v0.0.3 已打通固定逐层路由推理与评测。用户授权继续实施、频繁记录；可使用 GPU 0–7。过程见 [record](v0.0.4_train_stability_record.md)。

## 目标和顺序

1. 原生 Qwen 跑完整 IFEval／MATH-500，使用报告 non-thinking 采样与 32768 输出上限；核对官方 adapter，明确仍有 prompt／版本差异，不能称为完整论文复现。LCB 本轮先检查已有数据覆盖与截断。
2. 用固定公开真实语料替代 smoke fixtures，固定训练／开发划分、数据及 tokenizer 指纹，packing 不跨文档计算 attention／target。评测题不进入训练。
3. 正式训练入口支持 FSDP2、重计算、可选真实 compile、精确 CE＋教师 KL、断点恢复和 HF 导出。固定 E=R=36，保留绑定专家。
4. 实测 512／2048 序列长度 fixed／mixed 的热步吞吐、有效 targets、显存和路由分布。先短跑测量，再决定短程实验长度；不把 16-token smoke 外推成 24h 预算。
5. 对比同数据、同 token 数、同初始化的固定原层训练与缓慢开放路由训练。记录 prior、偏离原层比例、专家使用、开发 CE/KL；避免骤然撤掉先验。短跑不足以证明能力提升时如实报告。

## 保守决策

- 本轮先用小型公开人类指令数据完成训练链路和稳定性诊断，记录来源／许可与局限，不把它当最终多语种蒸馏配方。
- 数据独立于五类评测；训练仅使用训练 split，开发集用于稳定性判断，不用 benchmark 选 checkpoint。
- 固定层初始化的教师 KL 已接近零；CE 为主要学习信号，教师约束用于防止路由扰动后退化。
- 全参数 AdamW，FP32 master、BF16 计算；router 使用独立可配置学习率。冻结／开放实验以配置显式区分，不静默改算法。
- 先保持强先验再缓降。若始终未偏离原层，标记“未证明路由开放”；若明显退化则保留失败报告，不以继续训练掩盖问题。
- 预设短程实验，先测成本再扩展；不未经测量直接跑 24h。报告公平计算预算应包括教师开销。

## 验收

- 数据来源与划分可追溯；训练／开发样本不交叉，assistant target／packing 正确。
- 小模型恢复的下一步与不中断一致；真实 4B 多卡训练、保存、重启、HF 重载可用。
- 给出真实长度吞吐与 24h 可处理 token 估计，明确预热／验证／保存开销。
- 原生 Qwen 的完整 IFEval／MATH-500 有完整评分和截断审计。
- 固定／开放训练对照报告实际路由变化和开发损失；不保证短程就超过 Qwen。若瓶颈阻止收益实验，明确证据和下一步。

# 验证 Qwen3-0.6B 训练归因并修复确定性缓存推理

## 变更

迁移到 Qwen3-0.6B，使用 28 套绑定专家和原层序对照。新增真实监督 token 预算、CE-only 免教师加载、语料重分词、曝光审计和 GPU 4–7 限制；修复混合精度 QKV dispatch。

默认推理启用确定性算子，原生 Qwen 使用预分配 KV cache，减少长输出的重复解码。保留 packing、compile、FSDP、重计算和 HF 导出／恢复。

## 验证和结果

- 回归测试：57 passed；未训练参考路径在测试输入上的 eager logits、缓存 decode 和 HF 重载一致。
- 原生容量缓存与 HF DynamicCache：96 次真实模型对照 bitwise 一致。
- 六组独立 fixed28 训练覆盖 CE/KL、训练长度、数据覆盖和学习率；五组独立恢复／导出检查通过，250k 分支补验排队中。
- MATH-500：原生 49.20%，候选 47.00%；差值 −2.20pp，配对 bootstrap 95% 区间 [−6.00pp, +1.80pp]。IFEval 仍在运行。
- 最佳开发候选格式题 45/48，原生 46/48；数学均 48/48。未通过预设 2pp 工程门槛，因此未启动 10M/30M 动态主训练或新增 32B 生成。

P1 是原深度 SFT/KL 对照，尚未证明额外循环或动态退出收益。正式测试不参与选配方；相同生成上限不等于相同实际计算量。

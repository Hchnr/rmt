# 验证 Qwen3-0.6B RMT 训练归因并修复确定性缓存推理

## 变更

将本轮实验迁移到 Qwen3-0.6B，固定28专家及原层序对照，补齐真实监督token预算、CE-only免教师加载、数据重分词、曝光审计和GPU4–7限制。修复混合精度QKV dispatch，保留FSDP、packing、compile、重计算和精确恢复能力。

默认推理启用确定性算子，原生Qwen采用预分配KV cache；减少长输出的重复detokenize和历史集合构建。新增可复现的开发探针、训练配方对照、正式评测及逐题配对分析入口。

## 验证与结论

- 完整回归：57 passed；真实0.6B原层序、缓存decode及HF重载在测试输入上bitwise一致。
- 原生预分配cache与HF DynamicCache共96次真实模型对照bitwise一致。
- 六组独立fixed28训练覆盖CE/KL权重、训练长度、数据覆盖及学习率；实际曝光核验通过；五组独立恢复和HF容差验证通过，250k分支的独立检查待补。
- 最佳开发候选：格式45/48，原生46/48；数学均48/48。未通过预设2pp工程门槛，不能称为统计显著退化，也尚未证明质量恢复或架构收益。
- 按计划的质量门槛，未扩大到10M/30M、未执行动态主训练或新32B生成。正式评测状态和分数以reports/v0.0.5的完整审计为准，部分运行不作为最终分数。

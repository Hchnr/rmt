# 迁移至 Qwen3-0.6B，完成训练归因实验与确定性推理修复

- 使用 28 套绑定专家，补齐监督 token 预算、CE-only 免教师加载、数据重分词和实际曝光审计，修复混合精度 QKV dispatch。

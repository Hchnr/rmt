# v0.0.4：动态循环训练、固定退出策略与分阶段蒸馏

日期：2026-09-30。状态：**实施中：动态训练／缓存、H／P／H+P 配对短训及正确性验证已完成；32B 1k 教师生成与后续配对验收正在执行。原始建议保留作为决策依据，实际进展见过程记录。**

按用户指定使用本文件名；这是已有 v0.0.4 训练稳定性工作的后续专题，不覆盖 [原计划](v0.0.4_train_stability.md)、[原记录](v0.0.4_train_stability_record.md)及[阶段结果](../reports/v0.0.4/summary.md)。实施时使用独立的 `dynamic_recurr` 配置、产物及记录目录。

本文中“已确定”来自用户要求；“建议”是可修改的方案；“待选择”允许多选。退出策略选择与专家路由学习是两个独立维度：**退出策略可以固定，专家 router 和模型权重仍然可以训练**。

## 1. 目标与已确定范围

1. 从固定 36 次循环扩展到**不固定循环次数的训练**；训练和推理使用一致的退出语义。
2. 优先研究无需可学习 halting head 的固定策略；已确认“趋同”指**同一 token 在相邻迭代中的通道向量／分布趋于稳定**，并采用**每个 token 独立退出**。先分别实验 H（hidden 向量稳定）与 P（输出概率稳定），再评估 H+P。
3. 已确认平均循环目标 **40 次**、硬上限 **48 次**，保留固定 36／40／48 次对照，探索额外计算能否改善质量。平均目标在校准集上衡量，不承诺每个 batch 都精确达到。
4. 准备更大、可追溯的数据，已确认 **Qwen3-4B 正确性验证 → Qwen3-32B 离线 non-thinking 答案蒸馏**；14B 是可选成本／质量对照，不是必经阶段。
5. 保留 36 套绑定专家、text-only、HF checkpoint、packing、compile、FSDP2、重计算和 batched KV-cache inference。投影解绑另立实验。
6. 资源沿用 8×H100；先短程验证，再确定是否投入一次 24h 效果实验。
7. 超出 36 次的路径先做短程诊断：前 36 次保留原层序，比较尾部 8 套专家复用和从第 1 套重新循环，然后在稳定先验下开放专家路由；退出规则保持固定。

**研究假设而非前提结论：**多几次循环提供额外计算机会，但不保证质量上升。需要分别证明“更深训练有收益”“动态预算分配有收益”“更强教师有收益”；不能把三者混在一次实验中归因。

## 2. 当前证据与必须补齐的边界

当前基座为 `/share/project/eai_pwm/models/Qwen/Qwen3-4B`，36 套专家均由原始对应层初始化。基础参数 4,022,468,096；现有 router 93,456；合计 4,022,561,552。循环增加不复制专家权重。

现有开发集结果：固定层序训练 CE=2.02056，开放路由训练 CE=2.17900；同一开放权重强制原始层序后 CE=2.02464。开放路由尚未证明收益，因此新主实验建议从原始 Qwen 映射权重开始，已有训练 checkpoint 只作诊断对照。不要把带有既有数据适配的 checkpoint 与原始权重混用后直接比较。

代码核对发现：

- `modeling_rmt.py` 只有固定 `range(num_recurrences)`，没有 token active mask、退出时间或退出理由。
- `routing.py` 的 `step_bias` 是 `[num_recurrences, num_experts]`；超过 36 次涉及配置及权重迁移。
- `layer_order` 与 learned prior 当前都按 `step % num_experts`，第 37 次会回到专家 0。这个实现行为不能视为经过验证的继续推理策略。
- KV cache 按循环步保存，现有接口假设每个循环深度都有完整的历史 token，逐 token 退出需要新增语义。
- 当前教师加载逻辑固定为同一个 4B；更大教师需要独立模型、tokenizer 检查和生成／蒸馏适配。

本轮不要求先解决所有固定深度路由问题才能研究动态深度，但保留少量路径消融，以区分深度、专家复用和停止判据造成的影响。

## 4. 如何定义 hidden states 的“趋同”

令 `h[t, r]` 为 token 位置 t 完成第 r 次 cell 后、**共享 final norm 之前**的 residual stream，通道维为 d=2560。只在相同张量位置比较，指标归约用 FP32；padding 不参加统计。

### 4.1 两种含义需要区分

- **时间上的稳定，用户已选：**同一 token 的向量或通道分布从 r−1 到 r 变化很小。这可以作为退出候选信号。
- **通道间变得相同：**同一向量的各通道数值逐渐接近。不同通道通常承载不同特征，数值相同并非正确答案的必要条件；接近常量还可能是表示塌缩。默认仅记录 channel variance、RMS 和有效维度等诊断，不将其作为单独退出条件，也不训练模型去压低通道方差。

此外，通道直方图相同不等于向量相同。例如 `[1, -1]` 与 `[-1, 1]` 的直方图一样，但线性输出可以不同。必须区分保留 channel 索引的比较与丢弃索引的分布比较。

### 4.2 固定退出候选，可多选

| ID | 固定判据 | 优点 | 需要验证的风险 |
| --- | --- | --- | --- |
| H | 相邻循环归一化向量变化与相对更新幅度均低于阈值，连续满足 p 次 | O(d)，不用每步执行大词表 LM head | 残差积累可导致相对变化变小；稳定表示仍可能对应错误答案 |
| D | 通道能量分布的 JS 距离小，或固定直方图距离小 | 直接检验用户关于通道分布的设想 | 能量丢失符号，直方图还丢失 channel 身份；单独使用可能误判 |
| P | 相邻检查点的词表概率分布 JS／KL 小，连续满足 p 次 | 更直接反映 next-token 预测是否稳定 | LM head 及 softmax 昂贵；稳定也不等于正确 |
| H+P | H 连续满足后，用 P 复核 | 尝试减少 LM head 检查成本 | 需要真实测量复核触发率、漏检和总耗时 |
| L，可选 | 只用置信度／熵或 top-1 连续不变 | 容易实现，适合诊断对照 | 自信错误、top-1 不变但其余概率显著变化；不建议单独作为主方案 |
| ACT，后置 | 可学习 halting head 与计算代价 | 可另行研究自动预算学习 | 与本轮固定策略偏好不一致，默认不纳入实施 |

H 的建议定义：

```text
u_r       = h_r / sqrt(mean_channel(h_r^2) + eps)
delta_dir = RMS(u_r - u_(r-1))
delta_rel = RMS(h_r - h_(r-1)) / max(RMS(h_(r-1)), eps_scale)
stable_H  = delta_dir < tau_dir AND delta_rel < tau_rel
```

`eps`、`eps_scale` 和阈值作为显式配置。额外记录 RMS、cosine distance、两步振荡指标；不把 cosine 单一指标当充分条件。

本模型相邻循环可能选择不同专家，循环步先验也会变化，因此“小更新”并不意味着已经达到同一个迭代函数的固定点。连续检查只能降低偶然误判，不能证明后续其他专家不会产生有益变化；必须用继续计算的离线对照检验。

D 的一个可重复定义为 `q_c=(h_c^2+eps)/sum_j(h_j^2+eps)`，比较相邻循环的 `JS(q_r, q_(r-1))`。它不是词表概率或置信度；单独 D 与 D+H 均可诊断，不通过 loss 强行让 q 变均匀。固定直方图仅作另一个实验，不与该定义混称。

P 使用共享 final norm 与 LM head，固定温度得到完整词表概率。小规模校验先用精确分布；top-k 近似另记算法名，需处理尾部概率质量，不能直接把 top-k 内重归一化称为精确 JS／KL。H+P 在 H 首次满足时建立概率检查点，下一次满足时与其比较，未满足时重置；必须记录这种延迟，不声称完全等同于每步 P。

所有方案共同规则：

- 设 `r_min`、`r_max`、检查间隔、连续满足次数 p，建议起点 36／48／1／2。最小深度前可收集历史指标，但不允许退出；首次退出仍必须满足完整 p 个真实检查。
- 退出不可撤销；循环退出与 EOS 结束生成分别处理。
- 到 `r_max` 必须停止，理由记为 `max_depth`，不记为收敛。
- 非有限 hidden／指标在训练中立即报错并保存诊断，在推理中返回可定位错误；不能以“触顶退出”掩盖 NaN。
- 判据只能使用当前 token 的因果状态、当前循环及历史循环信息，不能读取下一个 token、标签、教师正确性或同批其他请求。
- 先观测，不添加鼓励隐藏状态趋同的损失。若以后加入一致性正则，必须单列实验，检查是否只是压小更新来满足停止条件。

Huginn 工作研究了随机循环深度训练及相邻输出分布 KL 的固定退出，支持将 P 纳入候选；其结构、预训练规模和 cache sharing 与本项目不同，论文阈值和效果不能直接移植。见[原论文 §3、§6.1–6.2](https://arxiv.org/html/2502.05171v1)。[ACT 原论文](https://arxiv.org/abs/1603.08983)仅作可学习退出的后续参考。

## 5. 平均循环预算与校准

已确认主目标为 `mean(R)=40`、硬上限 48；校准容差建议先用 `[39, 41]`。这对应 cell 次数比 36 增加约 11.1%，**不是实际 FLOPs 或延迟只增加 11.1% 的保证**。判据检查、专家分发、KV 搬运和稀疏执行都要计入。

分别记录以下口径，不能混为一个平均值：

1. 训练／teacher-forcing：所有非 padding 输入 token 的平均循环数；另报 assistant 监督预测位置均值。
2. 自由生成：prefill token 与 decode 输入位置分别统计，并报告 token 加权均值和请求加权均值。
3. 真正执行的 kernel／FLOPs、batch 最大深度和墙钟时间；参考版掩码执行到最大深度不能声称已节约被屏蔽计算。

阈值在与训练、开发选模、最终测试分开的 `halt_calibration` 数据上选择。建议先以 teacher-forcing 全有效 token 的 40±1 为初始目标，再在固定生成校准集单独测 decode 深度；若两者差异显著，明确选择部署主预算或引入显式 prefill／decode 配置，不能静默改口径。

校准流程：

1. 固定权重，在最大深度下记录稀疏探针，形成阈值候选；不保存全量巨大 hidden/logits。
2. 对小网格运行**真实退出及 KV 保留语义**，报告质量—平均深度曲线。shadow trace 只能帮助提名阈值，因为一个 token 提前停止会改变其他 token 的后续注意力，不能直接从全深度轨迹推算真实动态结果。
3. 在预算范围内按预先定义的开发质量规则选阈值；训练期间只在预设阶段边界重新校准，冻结到下一阶段。校准属于外部固定规则，不反传阈值。
4. 评测前冻结权重和阈值；不按 benchmark 分数回调退出。阈值变化会反馈到 token 间相互作用，不假定整体平均深度严格单调，不把二分搜索视为必然有效。

每次报告 mean／P50／P90／P99／max、各深度占比、触顶率、停止理由、语言／任务／长度分桶。大量样本全部停在同一个深度应标为动态策略退化；大部分触顶应标为判据未建立有效停止行为。目标平均值不可通过跨请求排名、读未来 token 或“凑配额”强制满足。

如果当前判据找不到兼顾质量和 40 次平均预算的阈值，就报告该策略未达标；不突破 48 次硬上限，也不把固定 40 次伪装成成功的自适应结果。

## 6. 超过 36 次的专家选择与参数迁移

停止规则固定并不指定第 37 次以后使用哪个专家。已确认先在小诊断集比较 R-cycle 与 R-tail，再逐步开放 R-learned：

| 路径 | 定义 | 用途 |
| --- | --- | --- |
| R-cycle | 前 36 次按原层序；之后继续 `step % 36` | 显式保留现有行为作为对照，不默认其合理 |
| R-tail | 前 36 次按原层序；之后循环专家 28–35（0 编号） | 靠近后层表示的保守候选；仍需训练验证，尾部范围是超参数 |
| R-learned | 36 次后允许 router 选择全部 36 套，先由明确先验约束，再按日程开放 | 正式成套专家复用研究；不能预设比固定路径好 |

前 36 次在诊断起步阶段保持原层序；后续可逐渐开放，但先与“前 36 次保持原层序、只开放追加部分”比较。第一批不同时改变退出判据、前段路由和教师；从小规模结果选一条明示主路径，失败路径保留记录。周期性路径另看同相位变化，周期稳定不能替代相邻输出稳定。

模型定义需要把 `num_experts=36`、配置默认固定深度、`max_recurrences`、请求实际深度、退出策略与专家先验表分开。旧 checkpoint 默认仍执行原 36 次，不能因增加字段改变旧输出。

建议将 `step_bias` 扩展到硬上限，原 36 行逐项保留、新行零初始化；循环先验单独显式配置。48 次只新增 `12×36=432` 个 bias 参数：router 变为 93,888，总计 4,022,561,984。这个统计以“仅扩展 bias、无新增可学习退出模块”的实现为条件，最终以实测参数清单验收。改变最大深度须显式迁移 checkpoint；中途 resume 不允许静默迁移。

## 7. 逐 token 退出、因果性和 KV cache

### 7.1 建议主语义：冻结退出状态，沿更深循环保留最后一次 K/V

对位置 t 定义退出循环 `R_t`。在 r≤R_t 时执行完整绑定 cell；在 r>R_t 时：

- residual stream 保持 `h[t,R_t]`，不再计算该 token 的新 Q、attention output、FFN，也不重新路由；输出只经过共享 final norm/head。
- 在 r=R_t 这次 cell 中，K/V 是由其输入 `h[t,R_t−1]` 和当时选定专家计算的。更深循环使用**这份最后实际产生的 K/V**，不把 final hidden 误称为它的来源。
- 后续仍 active 的 token 可以按原因果 mask 读取这些保留的 K/V。RoPE 只按原 token 位置应用一次，沿深度复用时不得重复旋转。
- 不为已经退出的 token 换专家补算部分投影；这避免在该 token 上隐含解除整套绑定。不同循环／专家间复用旧 K/V 的质量影响需要与固定全深度对照验证。

这是新增的、需要实验验证的模型语义，不能宣称与“这些 token 继续计算到最大深度”数学等价。如果该语义明显损害质量，可单列“冻结 hidden 后为深层重算 K/V”的备选；后者改变成本及部分投影执行语义，必须重新说明绑定边界和训练／推理一致性。

训练中使用同一规则保留本次 forward 的 K/V 张量；**不启用跨样本可变推理 cache，也不对这些张量 detach**，否则会丢失后来 token 经 attention 传回的梯度。退出条件的布尔判断无梯度，已执行模型计算保持完整 BPTT。

### 7.2 缓存实现和批量执行

- 正确性参考先用最大深度的矩形逻辑 cache，退出后的深度槽填入保留 K/V；这个版本缓存占用仍按 `r_max` 计，不能声称节约显存。
- 优化版可以用“已计算深度段＋退出后别名／惰性填充”，但每个深度对所有已入缓存位置都必须可读取完整合法历史。
- 若一个请求所有当前 token 提前退出，下一 token 走得更深时仍必须取得先前 token 的深层逻辑 K/V；不能以旧 cache 的缺槽代表空上下文。
- global token position 与各深度的物理分配进度解耦；cache 容量、reset、batch select/reorder、分块 prefill 和滚动 decode 全部纳入测试。
- 独立请求不能共享退出统计；packing 内每个 segment 的 mask、位置与稳定计数隔离。改变未来后缀、同 pack 的其他文档或无关批次成员，不能改变某个前缀的数学执行语义。
- FP32 判据降低舍入噪声但不保证 compile／batch 变化下退出相同；单独报告阈值附近的退出步分歧、logits 误差与质量。旧 36 次严格路径继续保留 bitwise 回归边界。

请求级预算只保留为对照：可先在请求开始前抽取固定预算，或只根据用户 prompt 决定整个请求预算，并在整个生成期间固定。**不能根据 teacher-forcing 的整条答案聚合 hidden 决定早期 token 的退出**，这会让未来内容影响早期预测；逐解码步根据整个前缀重选统一深度还涉及历史 cache 补算，另列方案。随机请求预算是动态训练对照，不等同于已选定的逐 token 内容自适应退出。

## 8. 动态训练目标与课程

### T0：退出观测和语义校验

不先改模型权重。在小模型及真实 4B 小样本上完成固定 36、固定扩展深度、H/D/P shadow traces、真实退出与 cache 检查。观察哪些指标与“继续算能否改善”相关；继续算的收益可以离线利用标签分析，但不能把标签提供给部署退出器。

### T1：随机深度预热

从原始映射权重开始；先做短固定 36 保护阶段，再逐渐引入 {36,40,44,48}。建议稳定后的采样概率为 {0.4,0.3,0.2,0.1}，期望 40 次。初版每个 optimizer step 在所有 rank 共享抽样深度，不由样本内容决定，降低分布式分支复杂度；深度 RNG 必须可恢复。

这个阶段让共享输出头、被复用专家和 router 接触多个深度。仅完成 T1 只能叫随机深度训练，**不能作为内容自适应训练完成的验收**。超过 36 次可能初始退化，需记录每个深度的 CE/KL、更新范数和专家使用率；持续退化先检查路径及适配，再增加训练预算。

### T2：真正按固定判据退出的训练

使用 H、P 或选定组合，对训练 token 执行相同的停止规则和 K/V 保留语义。主损失在每个预测位置的实际退出 hidden 上计算：

```text
L_main = CE(assistant targets, student_exit)
       + lambda_KD * T^2 * KL(teacher || student_exit)
```

- loss 的 label shift／文档边界沿用现有规则：位置 t 的退出表示预测 t+1，只对有效 assistant targets 监督。
- 阈值、停止布尔量不训练，不默认使用 ACT、REINFORCE 或停止决策的 ST 梯度；专家 router 可暂沿用现有代理梯度并单列局限。
- 保留少量事先随机选定的强制深度训练批次，建议 10%–20%，保证深层路径有训练信号。它们也进入平均训练深度和 GPU-hours 统计，不伪装成自然退出。
- 可选一个稀疏中间读出的 CE/KL 辅助损失，使用共享 head、不新增 exit head；只在仍 active 的有效预测位置归一化，零目标位置安全跳过。先做无辅助损失基线，再决定是否加入，记录额外 head 计算。
- 不为了控制平均深度而直接最小化 hidden 差异。固定规则仍可能被模型间接适应，需要检查早停率上升是否伴随能力下降。
- 一次训练不尝试所有策略。优先从 T1 同一个 checkpoint 分叉两个退出候选，固定后续数据与预算，减小归因混淆。

### T3：强教师与数据升级

T0/T1 的正确性和短程稳定性通过后即可启动大教师小批生成，并与 T2 形成有控制的实验；无需把“先证明动态架构超过 4B”设为大教师数据准备的前提。强教师带来的额外收益必须给固定 36／固定 40 对照使用相同数据。

### 9.2 划分、过滤和产物

- 在教师生成前按规范化题干／对话根 ID 及近重复组切分 `train`、`halt_calibration`、`dev`、`test`；同题不同教师、不同答案、改写版本必须属于同组。校准与 dev/test 不回流训练。
- 复用已有评测库存，扩展到计划声称覆盖的完整评测题源：规范化精确去重＋近重复检测＋可追踪源 ID 排除。尤其注意数学集合与竞赛题、代码题与 benchmark 的交叉来源；记录可检查范围，不能声称未知预训练数据完全无污染。
- 现有 500 条 dev 已参与多次实验，只作历史回归，新最终 test 在选择策略／阈值前冻结。
- 保留 non-thinking 格式；原数据含长 reasoning 时不直接截断成一个“完整答案”。重新生成、完整保留到另一长度桶或剔除；中断／截断记录不进入完整答案监督。
- 起步长度 2048，随后视分布增加 4096；长数学答案独立分桶，报告过滤比例与难度偏差。
- 数学优先验证可解析答案，代码优先运行独立测试；教师自评和格式检查分别记录，不当作正确性证明。
- packing 隔离 attention、position、halt state、label shift；不得由一个文档的退出状态改变另一个文档。
- 产物建议为 `sources.json`、`split_manifest.json`、`decontamination.json`、`teacher_generations.jsonl`、`tokenized_manifest.json`；包含 revision、文件 hash、模板／tokenizer hash、样本 ID、过滤理由、长度、教师和生成参数。大文件位于 git 忽略的 artifacts。

### 9.3 教师路线：4B → 32B，14B 可选

| 教师 | 建议角色 | 成本及边界 |
| --- | --- | --- |
| 本地 Qwen3-4B | T0/T1 的正确性与能力保持；现有精确 KL 参考 | 冻结，不随学生更新；单靠模仿自身不能作为超过自身的充分学习信号 |
| [Qwen3-14B](https://huggingface.co/Qwen/Qwen3-14B) | 可选同 prompt 成本／质量对照 | 已确定不作为必经阶段，不能只按参数更大认定样本更好 |
| [Qwen3-32B](https://huggingface.co/Qwen/Qwen3-32B) | 已选定的首个大教师，离线生成 non-thinking 答案 | 模型卡支持显式关闭 thinking；先测小批质量、截断率和吞吐，再扩大 |
| 更大 Qwen MoE／后续版本 | 后续质量瓶颈明确后再加入 | 不纳入首个 24h 必做清单；模型版本、模板、tokenizer 与预算重新审计 |

本机已检查的 Qwen 模型目录有 Qwen3-4B 和 Qwen3-VL-32B 等，尚无所述纯文本 Qwen3-14B／32B；不将 VL 模型静默替换为文本教师。计划阶段不下载大权重。

已选定大教师首先做**离线序列蒸馏**：提示词固定、生成完整答案、质量过滤、学生在相同问题和答案上做 CE；4B 的 KL 作为可调能力保持项。继而再试大教师分布蒸馏，避免每个学生训练 rank 放一个 32B 教师。生成服务先用已可用 HF 路线做正确性参考，性能不足时再适配独立 vLLM 环境，不重复无界安装尝试。

如做 logits 蒸馏：教师在与学生完全相同的 teacher-forcing token 前缀上评分；先核对完整 token→ID 映射、特殊 token、chat template 和 prefix tokenization，不只比较词表大小。hidden size 不同本身不妨碍各自 head 产生同一词表分布，但不能直接逐元素对齐 hidden。对不兼容 tokenizer 优先序列蒸馏；top-k 缓存目标单列近似误差、尾部质量、存储成本。

4B→32B 与 4B→14B→32B 的顺序效应不能冒充教师优劣。比较教师时从相同学生 checkpoint 分支、使用同一题目池和各自明确的回答版本，记录真实 targets 及生成成本。阶段性串行路线另行展示累计收益和累计预算。

thinking 轨迹留作第二阶段可选分支，显式区别可见 CoT token 与 latent recurrence。主线先维持 non-thinking，避免同时增加输出长度和内部循环而无法解释收益。

## 10. 工程实施顺序与性能约束

1. **配置和参考模型：**旧 36 次路径不变；新增最大深度、先验表、退出策略、token 状态及统计；tiny 模型先验证公式、因果性和梯度。
2. **动态训练：**接入实际退出 readout、分段重计算、数据 mask、独立教师接口和精确恢复；沿实际执行路径完整反传，不默认 truncated BPTT。
3. **KV 推理：**先实现可验证的矩形参考缓存，再实现有效 token 的 Q／FFN 跳算和惰性 K/V；完成 HF 导出重载、prefill、分块 prefill、cached decode 和 batch 生命周期。
4. **compile：**优先编译 cell／投影数值计算，退出控制在图外或使用固定边界和 active mask；避免把 `.item()` 驱动的动态循环宣称为完整无 graph break 图。记录编译次数、预热、graph break、host 同步、显存和实际速度；主推理性能配置启用可验证的 compile 路径。
5. **FSDP2：**不同 rank 活跃深度／专家可不同，但 collective 顺序必须一致。沿用根分片与整次 forward 参数驻留起点，循环内不引入按退出条件执行的 rank 局部 collective；全空 rank、未使用参数、不同停止深度、梯度归约必须测试。
6. **重计算与恢复：**固定判据、随机深度及强制深度批次在 replay 时一致，校准版本和状态写入 checkpoint；重算不允许重复修改全局停止计数或推理 cache。重启校验下一步 loss、深度分布和参数摘要。
7. **profiling：**分别测完全固定路径、保守开放路由及充分混合压力场景，报告 active token 比例、分发开销、Q/K/V 与 FFN 实际执行量。不能把 mask 后输出不变等同于跳过计算。

既有 8 卡 2048 长度测量中充分混合约比固定路径慢 12.49 倍，但这是约 97% 路由偏离的压力配置；短程保守开放候选约增加 32% 训练步耗时。动态循环需要新的端到端测量，不能线性按 40/36 或卡数推算吞吐。

## 11. 实验矩阵与归因

分阶段缩小选择，不要求一次跑完下表所有组合。

| 组 | 数据／教师 | 训练与推理 | 回答的问题 |
| --- | --- | --- | --- |
| B0 | 无新增训练 | 冻结原 Qwen3-4B，36 层 | 是否超过起点 |
| B1 | 与候选完全相同 | 原架构等价固定 36 路径继续训练 | 收益是否主要来自数据／教师 |
| B2 | 同数据／教师 | 固定 40；48 为小规模深度上界对照 | 追加计算本身是否有效 |
| B3 | 同数据／教师 | 随机深度训练；同一权重分别固定 36／40／48 和动态推理 | 多深度训练、推理深度与停止策略的作用 |
| B4 | 同数据／教师 | 真正固定判据动态训练＋动态推理 | 训练适应实际停止是否有额外收益 |
| B5，可选 | 同数据／教师 | 与 B4 深度分布接近的随机 token 退出 | 内容驱动分配是否优于相同平均预算的随机分配 |

B2/B3/B4 尽量使用相同专家路由／追加深度先验，路由日程变化另列消融。B5 的随机退出按 token 因果索引和独立 RNG 决定，训练／推理 K/V 语义相同；它只是诊断，不能从真实答案反推随机预算。

比较同时报告：

- 同训练有效 token：隔离数据量，列出不同 GPU-hours。
- 同训练 GPU-hours：隔离资源预算，列出实际消费 token；教师生成与训练分别及合计列账。
- 同平均推理 cell 数及实测计算／延迟：比较动态与固定 40 左右。动态平均 40 相对原生 36 属于更高推理预算，不能沿用原 ±5% FLOPs 公平口径声称同算力胜出。
- 质量—成本曲线：同一候选在多个深度／阈值上报告 CE、教师 KL、任务分数、延迟、吞吐、显存、退出分布；校准用数据与最终评测分开。

诊断首先检查：停止指标能否区分“多算有益／无益／有害”；稳定但错误的比例；触顶样本；最常见专家路径；相邻／两步／同相位振荡。完整展开路径可作诊断，但不能把离线挑选最佳停止步的 oracle 得分当实际模型成绩。

官方能力回归沿用已有 EvalScope 基础设施，先固定开发小集诊断，再对冻结候选完整跑 IFEval／MATH-500；后续扩展 Qwen 报告其余集合。现有原生完整分数 IFEval 80.41%、MATH-500 81.60% 只在协议可核对时复用；与报告仍有差距，不预先称论文完全复现。最终结论以同协议配对差异及不确定性为准，不能仅凭 CE 降低宣布通用能力超越。

## 12. 预算、阶段门槛与验收

先做工程正确性和小样本成本测量，再冻结一次 24h、最多 192 H100 GPU-hours 的实验配置。原始模型下载、语料审计和历史实验成本单列；本轮新生成教师数据的 GPU 成本纳入。不能承诺全部教师／策略／seed 在一个窗口内完成。

建议预算分段：诊断／校准与 profiling 最多 2h；大教师小批生成及验证最多 4h；主候选与固定对照训练合计最多 12h；评测最多 4h；恢复和关键复验预留 2h。各阶段可重分配但保持总上限。教师吞吐不足则缩小本轮生成样本量，不通过复用未经审计的数据隐藏成本。正式训练 token 预算由测量决定。

技术验收：

- [x] 固定 36 的兼容模式保留既有严格参考结果，配置迁移和参数增量清楚。
- [x] 至少一个固定判据实现真正动态训练；T1 随机深度预热不能替代该项。
- [x] 单 token、混合深度、全早停、全触顶、padding、packing、异常数值的行为可验证。
- [x] 全序列、分块 prefill、cached decode、batch select/reset 的 logits、停止步及误差边界明确；未来后缀变化不影响前缀语义。
- [x] 梯度可经过实际计算与保留的 K/V；tiny 模型用强制停止轨迹对照验证，不只看 loss 是否下降。
- [x] FSDP2＋重计算＋动态退出完成真实 4B 多卡训练、保存、重启、HF 重载；compile 性能路径单独验证真实执行和数值影响。
- [ ] 数据及教师生成来源可追溯，训练／校准／开发／测试独立，去污染范围和失败样本明确。
- [ ] 退出阈值冻结后给出平均深度、触顶率及 prefill／decode 分布，列出实际预算偏离。

研究验收不预设“必须正收益”：

- [ ] 固定 36／相近平均深度固定对照／动态候选具备可比训练及评测证据。
- [ ] 分别回答额外循环、动态分配、强教师带来的增益或退化；保留负结果。

# v0.0.4 阶段结果

状态：训练链路与短程对照已完成；完整原生评测和独占八卡吞吐仍在运行／排队。未完成项不作为验收通过。

## 已得到的结论

缓慢开放路由已经产生实际路径变化，短程训练没有崩塌，但本轮没有发现优于固定原层路径的质量证据。当前更适合先改进路由学习与执行效率，再扩大训练预算。

两组均从 Qwen3-4B 初始化，E=R=36，绑定整套投影和 norm；四卡、2048 长度、128 步，使用完全相同的 927,901 个有效输入 token 和 590,157 个 assistant targets。固定路径与开放路径的训练步耗时分别约 108.31／143.23 秒，后者为 1.3225 倍；这是同 token 对照，不是同 GPU-hours 对照，也不是 24h 效果实验。

开放日程：prior 从 4 开始保持 16 步，再用 112 步缓降至 3。FP32 master／BF16 计算、确定性 SDPA、FSDP2、重计算、精确 CE＋0.5×教师 KL；基础／router LR 为 1e-5／1e-4，AdamW weight decay 为 0。

## 全部 500 条开发样本

所有配置只计算一次 82 个唯一 pack、90,874 个监督 targets；CE 越低越好。

| 模型／执行路径 | CE |
| --- | ---: |
| 原始 Qwen 对应层路径 | 3.51414 |
| 固定路由训练后 | 2.02056 |
| 开放路由训练后 | 2.17900 |
| 同一开放权重，强制回原层路径 | 2.02464 |

同一权重回到原层路径后恢复到接近固定训练的水平，支持新增损失主要与路径改变有关。开发集含之前用于日程诊断的 32 条 pilot，独立于训练，但不是完全盲测的最终 test；英语 no_robots CE 下降不能直接解释为通用能力超过 Qwen。

开放模型的逐层选择偏离比例为 0.4474%，但至少一次改变路径的有效输入 token 占 14.30%，监督预测位置占 13.25%。不能把这两种比例混淆。最常见的是从 0 编号的 step 17→expert 12；转移计数只是描述，不构成逐题因果解释。

证据：[完整开发结果](holdout_opened.json)、[同权重路径消融](holdout_opened_layer_order.json)、[路由统计](trained_route_analysis.json)、[训练曲线](training_curves.svg)。

## 冻结 checkpoint 的能力回归

沿用 v0.0.3 固定 32 题、non-thinking、2048 输出上限；已核对题目、请求 seed 和生成配置相同。以下为逐题审计的精确比例（官方汇总会四舍五入）。

| 模型 | MATH 子集 | IFEval prompt strict |
| --- | ---: | ---: |
| 原始 Qwen | 27/32（84.375%） | 23/32（71.875%） |
| 固定路由训练后 | 28/32（87.500%） | 22/32（68.750%） |
| 开放路由训练后 | 27/32（84.375%） | 20/32（62.500%） |

开放模型的数学总分虽然与原模型相同，但两道题的得分改变；IFEval 有 11 道题得分改变，净减少 3 道通过。固定模型数学净增 1 道、IFEval 净减 1 道。样本很小，不构成提升或显著性结论；目前没有优先推广开放 checkpoint 的依据。

数学达到输出上限的比例：原模型 3/32，两种训练模型均为 1/32；IFEval 均为 0/32。候选在评测前冻结，未按 benchmark 选模型。详见 [配对结果与审计](trained_quality.json)。

## 可重复性与数值边界

- 两个真实 4B 候选都通过同进程和独立进程恢复检查：下一步 loss 和参数 SHA256 完全相同。小模型 eager／compile 同样通过。
- HF BF16 导出重载的 pilot CE 差分别约 0.000561／0.000354，小于明确门槛 0.005；这里是数值容差验收，不声称导出前后逐字节相同。
- 默认 SDPA backward 曾导致真实模型恢复时参数 SHA 不同；开启确定性算法后解决。旧失败候选保留且不纳入最终对照。
- 可选训练 compile 已在真实 4B 前向／反向执行。四卡 512 长度 LR=0 探针的三步热段加速约 1.163×，同批最大 CE 差约 0.01027、teacher KL 约 0.00072–0.00107（eager 为 0）。未建立编译训练质量等价，因此两组正式候选都保持 eager 投影。
- 29 项自动测试通过；最终汇总后如有实现变化再执行对应测试。
